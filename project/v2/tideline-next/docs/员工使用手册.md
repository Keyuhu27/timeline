## 二、首次使用 / 数据为空时

如果左侧「在管品牌」为空，或品牌详情页显示「今日暂无投放数据」，需先同步账户：

1. 点击首页右上角 **「同步广告主」** 按钮
2. 等待约 10–30 秒，页面自动刷新
3. 左侧出现真实门店品牌名后，即可正常使用

> **注意**：同步广告主会从巨量引擎拉取最新的账户列表和在投项目。每次部署重启后都需要点一次。

## 三、品牌详情页 — 数据说明

点击左侧任意品牌名（如「快乐蜂（中国）餐饮」）即可进入该品牌的详情页。

### 3.1 顶部概览卡片

概览数据来源是巨量本地推后台「**首页全域 statQuery**」接口，与你登录巨量后台首页看到的数字**完全一致**。

| 平台卡片名称 | 对应巨量后台位置 | 说明 |
|-------------|----------------|------|
| **今日消耗** | 巨量后台首页 → 消耗 | 截至当前时刻的总花费（¥） |
| **直播全域消耗** | 巨量后台首页 → 直播 → 消耗 | 仅直播场景的投流花费 |
| **短视频全域消耗** | 巨量后台首页 → 短视频 → 消耗 | 仅短视频场景的投流花费 |
| **全域成交金额（GMV）** | 巨量后台首页 → 成交金额 | 全域口径，含直播+短视频+其他场景 |
| **全域支付ROI** | 巨量后台首页 → 支付ROI | GMV ÷ 消耗 |
| **全域成交订单** | 巨量后台首页 → 成交订单数 | 当日完成支付的订单总数 |
| **订单成本** | 消耗 ÷ 成交订单数 | 平均每单花费 |
| **直播成交金额** | 巨量后台首页 → 直播 → 成交金额 | 仅直播场景的 GMV |
| **直播全域ROI** | 巨量后台首页 → 直播 → ROI | 直播 GMV ÷ 直播消耗 |
| **短视频成交金额** | 巨量后台首页 → 短视频 → 成交金额 | 仅短视频的 GMV |
| **活跃计划** | 项目管理 → 状态「投放中」数量 | 正在投放的计划数 |
| **暂停计划** | 项目管理 → 状态「已暂停」数量 | 当前被暂停的计划数 |

> **数据口径说明**：平台使用「后台全域」口径（pc_home_roi2），即巨量后台首页默认展示的数字，而非开放平台 API 报表口径。两者在 GMV/ROI 上可能有差异，以后台数字为准。

---

### 3.2 当日计划列表

列表展示该品牌下所有本地推项目（每行 = 巨量后台「项目管理」中的一个项目）。

| 列名 | 对应巨量后台 | 说明 |
|------|------------|------|
| **计划名称** | 项目管理 → 项目名称 | 项目原始名称；内部ID不显示 |
| **预算** | 项目管理 → 日预算 | 当前设置的日预算（¥） |
| **今日花费** | 项目报表 → 消耗 | 该项目当日累计花费 |
| **线索数** | 项目报表 → 表单提交/私信/电话 | 本地推核心转化指标 |
| **线索成本（CPL）** | 消耗 ÷ 线索数 | 平均每条线索的花费 |
| **点击率（CTR）** | 项目报表 → 点击率 | 广告被点击的比率 |
| **ROAS** | 项目报表 → 支付ROI | 当前项目 GMV ÷ 消耗 |
| **状态** | 项目管理 → 投放状态 | 投放中 / 已暂停 / 已删除 |

#### 计划操作

- **暂停 / 恢复**：点击状态右侧按钮，直接调用巨量引擎 API，实时生效（约 1–3 秒）。操作后页面自动刷新。
- **调预算**：点击「调预算」弹窗输入新金额，最低不得低于已消耗金额，输入后实时写入巨量。

### 3.3 规则触发记录

页面下方「规则触发记录」展示平台规则引擎对该品牌执行的自动操作（如自动暂停超预算计划），格式：

```
规则名 | 计划名 | 动作（暂停/恢复/调预算）| 结果 | 时间
```

对应巨量后台**「工具 → 自动规则 → 执行记录」**，但只展示平台规则引擎触发的记录，不含巨量自身规则。

## 四、如何拉取日报

### 步骤

1. 在左侧点击目标品牌，进入品牌详情页
2. 点击右上角 **「同步状态」** 按钮，等待数据刷新（约 5–10 秒）
3. 数据刷新后，点击 **「生成日报」** 按钮
4. 平台调用 AI（Claude）分析当日投放表现，自动生成结构化日报
5. 日报内容包含：
   - 今日消耗 / GMV / ROI 总结
   - 各计划表现排名（高效 / 低效 / 超预算）
   - AI 优化建议（可选择采纳 / 忽略）
6. 日报生成后可直接复制文本，或截图发给客户

### 拉取日报前的注意事项

| 检查项 | 说明 |
|--------|------|
| 时间 | 建议在当天 **18:00 后**拉取，数据更完整 |
| 数据来源 | 确认概览区「今日消耗」有数字（非 ¥ 0.00），否则 Cookie 可能已过期 |
| Cookie 过期 | 如消耗为 0 且昨天正常，通知负责人更新 COOKIE 配置并重新部署 |

## 五、常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 品牌列表为空 | 首次启动或重新部署后未同步 | 点「同步广告主」 |
| 今日消耗显示 ¥ 0.00 | 后台 Cookie 已过期 | 联系负责人更新 Cookie |
| 点「暂停」没反应 | 网络超时或巨量 API 限流 | 稍等 10 秒后刷新页面重试 |
| 计划状态没更新 | 巨量延迟（通常 < 1 分钟） | 点「刷新数据」 |
| 日报生成失败 | ANTHROPIC_API_KEY 未配置 | 联系负责人检查 AI Key |
| 活跃计划数不对 | 开放平台同步延迟（约 5 分钟） | 再次点「同步状态」 |
